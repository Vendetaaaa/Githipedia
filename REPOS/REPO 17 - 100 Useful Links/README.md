# 100 Useful GitHub Links

*Every tool, doc, and rabbit hole worth bookmarking, sorted, so you don't have to dig.*

---

## What Is This?

There are thousands of "awesome GitHub" lists floating around, and most of them are either outdated, dumped in one giant unsorted blob, or half broken links. This one is grouped by what you're actually trying to do : build a profile, automate something, stay secure, learn the basics : so you can jump straight to the section you need instead of scrolling forever.

100 links. 10 categories. No fluff.
